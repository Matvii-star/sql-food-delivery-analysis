# sql-food-delivery-analysis
## Project Overview

This project analyzes a food delivery dataset using PostgreSQL. The goal was to explore business performance, identify operational insights, and practice SQL skills commonly used in Data Analytics.

The analysis focuses on revenue, restaurant performance, delivery efficiency, payment methods, discount usage, and refund trends.

---

## Dataset

The dataset contains approximately 1,000 food delivery orders and includes information about:

- Orders
- Customers
- Restaurants
- Order and delivery timestamps
- Payment methods
- Discounts and promotions
- Delivery fees
- Refunds and chargebacks

## Business Questions

### Data Quality

- How many records are in the dataset?
- Are there any missing values?
- Are there duplicate orders?

### Revenue Analysis

- What is the total revenue?
- Which restaurants generate the highest revenue?
- What is the average order value?
- Which restaurants have the highest average order value?

### Delivery Performance

- What is the average delivery time?
- Which restaurants have the slowest delivery times?

### Payment Analysis

- Which payment methods are used most frequently?
- Which payment methods generate the most revenue?

### Discount Analysis

- Which discounts are used most often?
- Do discounts affect average order value?

### Refund Analysis

- How much revenue is lost through refunds?
- Which restaurants have the highest refund amounts?
